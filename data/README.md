# データについて

このテンプレートには**データが同梱されていません**。開催回ごとに対象地域のオープンデータを
用意し、`workshop.config.json` を書き換えて使います。

## データを選ぶときの条件

- **エンティティ数が 1,000 件以下**（無料プラン T0 の上限）。件数が多いデータセットは
  区・路線・年度などで絞り込んでから使う
- **緯度・経度の列がある**（住所しかないものはジオコーディングが必要になり手間が増える）
- **CSV（できれば UTF-8）**。Shift_JIS（CP932）の場合は事前に変換しておく
  （`iconv -f CP932 -t UTF-8 元ファイル.csv > 変換後.csv`）
- **再配布可能なライセンス**（CC BY など）。作品を公開する画面には出典表示が必要
  （`workshop.config.json` の `attribution` に設定する）

## 手を出すと詰まりやすいもの

- 拡張子が `.csv` でも**中身が XLSX**（`head` すると `PK` で始まる）
- CP932 の ZIP に入った Shapefile（GDAL / ogr2ogr が必要）
- 座標が度分秒（`35°7'20"`）表記で、十進度への変換が必要
- 人間向けの整形（見出しが数行目にある、ファイルが区・年度ごとに分かれている）

## データの置き方

1. CSV を `data/<データセット名>.csv` として置く（`.gitignore` はしていないので git に入る）
2. `data/README.md`（このファイル）に出典・ライセンス・取得日・件数・列構成を書く
3. `workshop.config.json` の `entityType` / `fields` / `attribution` を対象データに合わせる
4. CSV → NDJSON の変換スクリプトは当日 AI に書かせる（`AGENTS.md` の「データモデル」参照）
