# データについて

## 同梱データ

`nagoya-emergency-water-supply.csv`

| 項目 | 内容 |
|---|---|
| 名称 | 応急給水施設一覧表 |
| 提供 | 名古屋市（上下水道局） |
| ライセンス | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.ja) |
| 配布元 | https://data.bodik.jp/dataset/231002_6101130000_01 |
| 取得日 | 2026-09-03 |
| 件数 | 617 行（欠損座標なし） |
| 文字コード | UTF-8（BOM 付き） |
| 列 | ID, 施設名, 施設名フリガナ, 施設種別, 区・町名, 住所, 緯度, 経度 |

配布元から取得したものを**無加工**で置いています。加工結果は別ファイルに出力してください。

施設種別の内訳: 地下式給水栓 398 / 仮設給水栓 204 / 常設給水栓 15。

作品を公開するときは出典表示（CC BY）が必要です。テンプレートでは画面右下に入れてあります。

## 他のデータを試したい人へ

名古屋市のオープンデータは [名古屋市オープンデータカタログサイト](https://odcs.bodik.jp/231002/)
（実体は BODIK の CKAN、データセット名は `231002_*`）から探せます。API でも検索できます。

```bash
curl -s "https://data.bodik.jp/api/3/action/package_search?q=name:231002_*+res_format:CSV&rows=5" | jq '.result.results[].title'
```

**無料プランはエンティティ 1,000 件まで**なので、データを選ぶときは件数を先に確認してください。

### 座標付きで確認済みのデータセット

| データセット | 件数 | 状態 |
|---|---|---|
| 応急給水施設一覧表 | 617 | ◎ そのまま使える（同梱データ） |
| 市バス停留所一覧 | 3,877 行（停留所コードで 1,482） | △ 1,000 件超。区や路線で絞れば使える |
| 市有防火水槽一覧 | 1,838 | △ 1,000 件超。文字コードは CP932 |
| 地下鉄駅のAED設置状況 | 90 | △ 緯度・経度の列が全行空。住所からジオコーディングが必要 |
| PM2.5 成分分析結果 | 数地点 | △ 座標が度分秒（35°7'20"）表記。十進度に変換が必要 |

### 手を出すと詰まるもの（時間内には厳しい）

- **公衆トイレ一覧** — 拡張子は `.csv` だが**中身は XLSX**（`head` すると `PK` で始まる）
- **指定避難所 / 指定緊急避難場所** — CP932 の ZIP に入った Shapefile。GDAL（ogr2ogr）が必要
- **都市公園一覧** — 区ごとに 16 ファイル、人間向けの整形（見出しが 3 行目、座標列なし）
