## 各パートで必ず言うこと

### セットアップ（0:10–0:30）

- **`.env.local` を書き換えたら `npm run dev` を再起動する。** Vite は環境変数を起動時にしか
  読みません。ここは毎回誰かが踏みます。
- この時点で「データを取得できませんでした」が出るのは**正常**。データが空なだけです。
  赤い枠を見て手が止まる人が出るので、先に宣言しておきます。

### CLI（0:30–0:50）

- 属性は `{ "type": "Property", "value": ... }` の形。素の `"name": "..."` では通りません。
- 位置は `location` という名前の `GeoProperty` に固定。名前を変えると地図と地理検索が動きません。
- `-f geojson` を見せると「CLI の出力がそのまま地図データになる」ことが伝わります。

### 変換（0:50–1:20）

先に釘を刺しておくと事故が激減する 2 点:

1. **座標は `[経度, 緯度]`。** CSV は「緯度, 経度」の順なので入れ替えが必要。間違えると
   アフリカ沖に点が並びます（毎回誰かがやるので、むしろ見せると盛り上がります）。
2. **CSV の先頭に BOM がある。** 1 列目のヘッダ名が `ID` ではなく `﻿ID` になり、
   ID が `undefined` になります。

AI への頼み方は README の手順 4 のプロンプトをそのまま投影してください。

### 投入（1:20–1:35）

- `--dry-run` を先に見せる。「送る前に確認する」癖をつけてもらう枠です。
- `--batch-size 100` は無料プランの上限。外すと 400 が返ります。
- 同じ `id` なら上書き（upsert）なので、**失敗しても何度でもやり直せる**ことを伝えてください。
  これを言わないと、失敗を怖がって手が止まります。

### 公開（2:50–3:00）

- Settings → Pages → Source = **GitHub Actions**（ここを忘れる人が必ず出ます）
- 接続先は Actions の **Variables** に入れる。ブラウザ側は匿名の読み取り専用なので、
  API キーを公開する必要はありません。この設計理由も一言添えると、そのまま実務の話になります。

## 詰まりポイント一覧（巡回時のチェック）

| 症状 | 見るところ |
|---|---|
| 地図が真っ白 | `http://localhost:5173` で開いているか（`127.0.0.1` は不可）。`VITE_GEOLONIA_API_KEY` を書き換えていないか |
| 403 `no applicable policy` | テナント名の綴り。`npm run dev` を再起動したか |
| 点が海の上 | 座標が `[緯度, 経度]` の順になっている |
| ID が `undefined` | BOM を落としていない |
| import が 400 | `--dry-run` の出力を一緒に読む |
| 0 件のまま | `g entities list --type EmergencyWaterSupply --local --count-only` で入っているか確認 |
| AI が迷走 | 一度に頼み過ぎ。`git checkout -- .` で戻して 1 つずつに分ける |

詳細な対処は [TROUBLESHOOTING.md](TROUBLESHOOTING.md) にあります。参加者にはまずこれを見せてください。

## AI 環境について（当日までに確認すること）

使うのは **opencode**（ターミナルのエージェント）+ **Big Pickle**（無料モデル、コンテキスト 200K）。
モデルはリポジトリの `opencode.json` で固定してあるので、参加者はモデルを選ぶ必要がありません。

**当日までに主催者が一次情報を取っておくこと:**

- Big Pickle は「**期間限定**の無料提供」とされているモデルです。当日も無料で使えるか、
  前日に `opencode` の `/models` で確認してください。
- `https://opencode.ai/auth` の**サインアップにクレジットカードが必要かどうか**。
  公式ドキュメントの手順には "add your billing details" が含まれますが、
  Big Pickle 等の無料モデルについては「カード不要」とする情報もあり、**一次確認が取れていません**。
  必ず**新規アカウントで一度サインアップを試して**から参加者に案内してください。
- 上の 2 つが崩れていた場合の代替: **Gemini API の無料キー**（Google AI Studio で発行、
  カード不要、Gemini 3 Flash で 15 RPM・1,000 リクエスト/日、期限なし）を opencode の
  `/connect` で Google プロバイダーとして接続する。`opencode.json` の `model` を
  `google/gemini-3-flash` 等に差し替えれば同じ進行で通せます。
